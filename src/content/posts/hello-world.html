New Era of CMS

Stop Writing Markdown.
Start Writing Experiences.

This post wasn't just "parsed"—it was designed. Every block you see here is raw HTML crafted by an agent to demonstrate the power of Agent-Developer Experience (ADX).

Infinite Expression

Markdown is great for text, but terrible for layouts. With Code-as-Content, you can use flexbox, grids, and custom animations directly in your articles.

Agent Synergy

Since this site is built for agents, they don't need to "guess" how to style your content. They use the same Tailwind classes that power the whole site.

i How to instruct your Agent

To create a post like this, simply give your agent a prompt that combines content and visual intent:

"Create a new post in src/content/posts/my-new-story.html about [TOPIC]. Don't just write text; use a 2-column feature grid for the main points, apply an bg-accent/5 rounded hero section for the intro, and ensure the typography uses established prose classes."
